# ADR 0002：前台有效阅读信号

日期：2026-10-12。状态：本次贡献采用。补充 [ADR 0001](0001-following-weights.md)。

## 来源与目标

按用户要求适配旧项目的详情页逗留学习。阅读只是本地兴趣线索，不跟踪 GitHub 新标签页，也不扩大授权或引入服务器。

## 决定与理由

- 只有详情页可见且获得焦点时累计 `performance.now()` 单调时间。失焦、隐藏、pagehide 暂停，路由、仓库或账号变化结束本次访问。
- 累计严格超过 3 分钟，或严格超过 1 分钟且打开本页原仓库时，记录一次权重 0.3 的 `dwell` 反馈。只认当前原仓库链接，保留新标签页、键盘和中键行为；作者、官网、复制 clone 不计外跳。
- 同账号、同规范仓库名 24 小时最多一次。最多 1000 个活跃去重项，满额暂停新增，不驱逐有效记录后重复加权。
- 写入时复核账号和推荐重置代次，旧页面或迟到 timer 不能向新账号或已重置推荐写入。重置清除阅读去重，保留收藏、稍后再看和历史。
- 继续兼容 `version:1`，逐项过滤新增时间戳和未知反馈种类；缺失新增字段不影响旧收藏。

## 验收

注入时钟验证严格阈值、前台累计、暂停/恢复、外跳及清理；验证 24 小时、1000 条容量、重置和账号竞态。运行 `npm test` 与 `npm run build`，详情原链接仍采用现有 GitHub URL 与浏览器导航。实际结果记录在对应 PR。
