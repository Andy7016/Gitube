# ADR 0008：图谱分支、相似度大小与聚焦视图

日期：2026-10-11。状态：已采纳。补充 [ADR 0005](0005-technical-provenance-graph.md) 的前端布局与交互，采集、证据和预算规则继续有效。

## 来源与目标

用户提供一级与多次手动展开后的截图：同尺寸节点难以表达相关性，所有后代继续挤在根仓库的两个圆环中；黄色②③重复且不能清楚表达父子关系。要求节点大小体现 topic 重合度，至少 30% 时常驻名称，选中后淡化无关关系，分开放置展开分支，并可把选中节点移到视觉中心。

## 决定与理由

- 保留原生 SVG 与确定性布局，不引入随机力导向或新的图形依赖。一级直接来源与开发者关联仍有内外档；手动后代按结构父节点分组，展开父节点和子树留出独立空间。相同节点只绘制一次，共享的来源边继续保留。
- 布局父节点由根可达的实际边确定：优先最短跳数，再按直接来源优先、既有项目排名与稳定名称决胜，形成无环结构树。递归计算每个局部子树的包围圆，父级为兄弟子树预留独立空间，展开父节点随整个分支外移；后代围绕其父节点向外延展，避免重新挤入根的圆环。`overlapRoot` 继续只表示重合度的比较基准；同一节点合并到更强相似度时，不借此悄悄改变其来源含义。
- 节点面积随真实 topic Jaccard 重合度增加，限定最小与最大尺寸。语言相同回退与无标签均按最小相似度尺寸显示；来源面板仍明确说明回退依据，不把语言回退的内部排序分数解释成 topic 百分比。
- 根、当前选中节点、展开分支的父节点及真实 topic 重合度至少 30% 的节点常驻名称。移除节点上②③数字徽标；来源面板保留明确的层级与父路径信息。
- 小预览和密集概览统一缩小普通节点，保留其相对面积关系；聚焦后恢复适合阅读的尺寸。常驻标签在屏幕空间确定性避碰，必要时用无箭头的细引线连接节点；引线只标注名字，不作为技术来源边。不能靠隐藏达到阈值的名称来掩盖密度问题。
- 选择节点突出它的一阶相连邻域，淡化无关节点和箭头。聚焦仅改变摄像机的位置与缩放，不改变根仓库，不启动新的网络追溯；查看全图恢复整体关系。保留独立的“以此节点为新根”操作。
- 提供全图适配、选中节点居中、缩放与拖动，兼顾键盘选择、窗口尺寸变化、全屏和减少动画偏好。详情内嵌区域保持固定高度，证据在面板内部滚动。

## 取舍与验收

展开分支需要更多画布空间；完整概览承担定位作用，聚焦与缩放用于阅读密集分支。未展开的同档子项仍依既有排名确定近远；为容纳子树，展开父节点可整体外移，因此多层图中距离根的绝对距离不再表示相似度，节点大小与来源面板保留真实比较基准。自动仍只追溯一级，后续逐节点手动启动；120 个节点与 5 层上限不变。布局和摄像机属于呈现，不推断新的引用或维护关系。

验证稳定排序与结构父归属、节点大小与回退语义、深层分支隔离及上限几何；浏览器检查标签阈值、邻域淡化、居中与全图、手动请求次数、键盘、拖动、缩放和深浅主题 / 手机布局。最终证据追加到 [验收记录](../acceptance.md)。
