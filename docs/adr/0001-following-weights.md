# ADR 0001：本地关注者权重

日期：2026-10-12。状态：本次贡献采用。

## 来源与目标

在当前 Gitube 中逐项适配旧 GithubImmersion 的推荐功能，遵循 README / CONTRIBUTING 的共享前端、直接请求 GitHub、无自建服务器约定。旧项目和已撤回的 [PR #1](https://github.com/Andy7016/Gitube/pull/1) 仅提供功能与验收参考；不恢复其服务端。

## 决定与理由

- 使用当前 `fetchFollowingStars` 的最多 50 位关注用户、每人 6 个近期 Star 样本，不新增请求、权限或抓取范围。设置仅列出实际获得动态的账号，说明采样局限。
- 按人设置 0–3 倍、步长 0.25，默认 1 倍。先对每人的仓库去重，再分摊 topic 总预算 `1.2 × 权重`，语言贡献为其一半，按 Star 时间采用 30 天半衰期。按人归一避免样本多的人天然占优。
- 0 倍同时移除该人的画像与正常推荐社交排序影响；不取消 GitHub 关注，原始关注频道继续显示其动态。
- 保持本地数据 `version:1`，缺失字段补默认值，非法权重逐项丢弃，不因此清空收藏。权重和存储键按 GitHub 账号小写隔离；防抖保存捕获对应账号快照，切账号前写回旧账号。
- 权重修改用于后续分页和换批，不替换已经看到的列表。完整前台恢复和探索的生命周期见后续 ADR。

## 验收

验证按人归一、权重线性、0 倍与重复样本、时间衰减、社交候选顺序、旧存储兼容和账号切换。运行 `npm test`、`npm run build`；设置检查浅色、深色、窄屏与滑杆持久化。实际结果记录在对应 PR。
