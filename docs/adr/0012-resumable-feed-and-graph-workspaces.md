# ADR 0012：恢复推送进度与图谱工作区

日期：2026-10-11。状态：已采纳。补充 [ADR 0010](0010-recommendation-controls-and-reading-signals.md) 与 [ADR 0008](0008-graph-branches-and-camera.md) 的页面状态寿命。

## 来源

用户要求返回首页、切换模式后保存推送进度，直到手动换一批或再次启动；技术图谱也保留上一次记录，直到下一次主动搜索。此前推荐模式切换清空同一 `foryou` 列表，图谱重新挂载会提交一级分析。

## 决定与理由

- 本次 SPA 运行期间，频道与推荐模式各自保存已加载列表、分页状态和滚动位置。首次访问没有缓存的模式允许检索；返回已有模式恢复其批次。页面刷新视为重新启动，允许重新抓取，不把实际 GitHub 候选永久保存为本地演示内容。
- 切模式使旧在途结果失效，但保留已完成批次。兴趣与关注者权重变化用于后续换批 / 分页，不自动替换当前列表。屏蔽和账号隔离仍即时生效，重置推荐清理所有模式状态。
- 恢复已有列表时，底部哨兵重新挂载不能立即发起搜索；用户再次表达滚动意图后继续正常无限分页。历史导航快照携带模式，避免旧 normal 快照覆盖 random 列表。
- 图谱按账号与根仓库保存最多 8 根的运行内工作区，包括合并结果、手动展开、选中节点、视角、信息面板与终态信息。独立与内嵌视图分别保存；返回已保存根不重新提交或轮询。独立入口恢复最近的独立工作台，嵌入其他仓库不改变其选择，也优先保留该工作台免于同账号详情浏览淘汰。
- 显式提交搜索表单总是重新分析，即使目标根已有缓存；普通导航或节点设为新根则可恢复已有结果。重新分析或手动追溯仍按用户操作执行。离页中断请求不向新页面写结果，返回后提供手动继续；刷新失败保留先前可用图。不保存 Token / CSRF，不拿旧会话任务 ID 恢复轮询。画布尺寸变化时适配视角。

## 验收

检查模式切换往返后的仓库顺序、滚动与网络次数；覆盖换批、慢响应、屏蔽、账号隔离和重置。图谱检查一级及多层结果恢复、选中与摄像机、独立入口、重新分析、离页中断及工作区上限。可复现结果见 [验收记录](../acceptance.md)。
