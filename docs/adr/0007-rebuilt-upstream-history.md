# ADR 0007：基于重建后的 Gitube 历史合并既有实现

日期：2026-10-11。状态：已采纳。替代 ADR 0006 的上游版本基线与“尚无 Git 仓库”状态，保留其功能设计。

## 来源与目标

用户要求从 [Andy7016/Gitube](https://github.com/Andy7016/Gitube) 拉取移除旧个人身份信息后重建的仓库，再合入已实现内容。新上游 main 为 `418daee527607dd0a97b1c8d675bf0a7a4895ecf`。本次授权是本地拉取与合并，没有远程推送或发布。

## 核对与决定

- 独立克隆重建版，逐字节比较两次上游的已跟踪文件：业务源码、package / lock、配置和许可证一致；只更新了中英文 README，新增 `docs/screenshot.png`。既有 Gitube 适配层因此可直接沿用，无需重新应用旧认证或覆盖已验证的图谱。
- 当前目录原本没有根 Git 仓库。现在新建根仓库，直接 fetch 重建版 main，以其 HEAD / index 建立本地 `integration/auth-graph` 分支；保留工作文件作为合并改动，不对工作树执行 hard reset，不把旧克隆的 `.git`、提交或补丁元数据复制进来。
- 默认前端继续位于 `gitube/src/`；保留根 `src/` 作为旧界面恢复入口。`server/`、测试、接口和设计文档一并进入可审阅的本地改动。原目录和同源站点地址保持不变，因此无需迁移本机 GitHub App 凭据或浏览器本地收藏。
- 更新上游截图、图标和 MIT 许可证；保留上游 Tauri 源码。浏览器认证、账号画像和追溯依赖 Node 服务，沿用 ADR 0006 的 Web 运行范围；不启用原静态 Pages 和桌面发布工作流，不宣称桌面包已完成集成。
- 清理重建前的本地上游缓存。文档以本 ADR 明确更新来源，不继续保留旧提交链接或真实身份；保留原设计理由与验收历史。MIT 的公开账号署名 Andy7016 继续保留。
- `.local/`、`.artifacts/`、依赖与构建输出被忽略，独立实验目录 `oneshot-astra/` 单独排除。只合入已知项目文件，不批量纳入整个工作区。未自动创建带本机推断身份的提交；本地改动可直接审阅。

## 验收与边界

检查新仓库所有引用 / reflog 与旧历史没有提交交集；新上游 author / committer 邮箱均为 GitHub noreply 格式。对可纳入文件和新历史对象检查旧身份匹配，只报告数量，不把旧姓名或邮箱再次写入材料。此检查只覆盖已知旧身份与当前本地对象，不能保证第三方服务器已清除历史缓存。

构建默认 Gitube 与保留的 RepoFlow，运行后端测试和浏览器关键回归；本机凭据只校验文件元信息与 Git 忽略状态，不输出内容。实际结果追加到 [验收记录](../acceptance.md)。图谱上限与推荐研究记录继续有效，本轮不改变推荐算法。
