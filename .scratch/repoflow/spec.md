# RepoFlow 第一版规格

来源：2026-10-09 当前用户请求。实现模型按用户指定采用 GPT-6.1 Sol / xhigh；未委派 Luna。

目标：实现一个可本地运行的中文 GitHub 项目推荐前端，借鉴 B 站 / YouTube 内容发现交互，支持登录、个性化兴趣、快速收藏及真实 Star。

验收：

1. 无 OAuth 配置可直接浏览标示清楚的演示首页；响应式项目封面卡片、导航与搜索完整。
2. 搜索、主题/语言、推荐/趋势、分页、详情、不感兴趣和恢复均可操作。
3. 收藏与兴趣持久化，访客/演示/不同账号隔离。
4. 配置 GitHub OAuth 后可登录；以服务端会话代理 GitHub，不向前端暴露 Token。
5. Star / 取消 Star 对真实账号通过 API 执行并处理失败；演示 Star 独立。
6. 构建与风险相关自动化测试通过，浏览器验证主要交互与移动端无横向溢出。

设计来源见 [ADR](../../docs/adr/0001-github-auth-and-recommendations.md)；最终证据见 [验收记录](../../docs/acceptance.md)。用户未授权发布到远程或操作其真实 GitHub 账号，未执行这些动作。

## 2026-10-09 截图反馈变更

用户要求以 YouTube 形式和交互为准，移除演示数据与宣传语，全部读取真实 GitHub；登录使用浏览器跳转，不手动编辑配置。原验收 1/3/4/5 中的演示和手动配置方案已被取代。当前持久规格移至 [docs/specification.md](../../docs/specification.md)，决策见 ADR 0002。
